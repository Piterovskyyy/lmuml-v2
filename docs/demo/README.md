# LMuML demo

The [application gallery](../../README.md#application-gallery) contains 31 desktop and phone pairs, including match and admin dialogs, account flows, and comfort mode. The screenshots come from a running build with fictional clubs, players, predictions, and results. Desktop views use a 1440 px viewport, and phone views use a 390 px viewport.

The gallery uses separate synthetic league and knockout data. A local test inbox was used for the password reset flow. The [local rehearsal](../operations/rehearsal.md) starts with two sample fixtures in its own database.

| Preview | What to look for |
| --- | --- |
| [Desktop home screen](gallery/desktop/player-home.webp) | The active round and shortcuts to standings and fixtures |
| [Mobile predictions](gallery/mobile/player-predictions.webp) | Score fields and confirmation that a prediction was saved |
| [Desktop standings](gallery/desktop/player-rankings.webp) | Player positions and points from completed rounds |
| [Player walkthrough](przebieg-gracza.webp) | Opening a round, saving a changed prediction, and viewing the rankings |
